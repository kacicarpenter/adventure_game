# Disaster Escape Adventure Game
An interactive, text-based adventure game developed in Python where players make decisions to survive natural disasters. Each choice affects the player's health and determines whether they win or lose.

# Features
- Allows players to choose between different scenarios involving an earthquake or tsunami.
- Uses conditional statements to create different paths based on player decisions.
- Calculates the player's remaining health based on their choices.
- Tracks the player's decisions using a list.
- Determines whether the player survives based on their remaining health.

# Skills Used
- Python
- Functions
- Parameters and Return Values
- Conditional Statements
- Lists
- User Input
- Debugging

# How to Run
1. Download `adventure_game.py`.
2. Open the file in a Python environment.
3. Run the program.
4. Follow the prompts and make decisions to survive the disaster.
